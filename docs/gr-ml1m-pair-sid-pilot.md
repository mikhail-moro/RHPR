# ML1M pair SID compression pilot

Question: can a mini-TIGER preserve next-item ranking when the older half of its history is represented by three semantic tokens per ordered pair instead of four tokens per individual movie? A negative result is a valid result.

Uses the frozen clean ML1M cohort and raw windows: 151166 train examples, 2786 validation users, up to 20 history movies. It does not evaluate test. For each history, remove padding, take floor(length/2) oldest movies, combine adjacent non-overlapping pairs left to right and preserve an unpaired final old movie. Recent movies remain unchanged. The pair is described as `First movie: {title+genres} Second movie: {title+genres}` using the pinned Sentence-T5; each ordered pair is cached once. Train has 121129 unique pairs, validation 13134, union 124812. The quantizer is fit uniformly on distinct training pairs, excluding pairs present only in validation; those are encoded using the frozen model. Context timestamps can tie: within-timestamp ordering is the existing item-ID tie-break, not evidence of watch order.

Train GRID normalized residual mini-batch KMeans separately on the 2874 item representations and train pair representations, 3x256, 10 passes per level. Use seeds 42 and 101. Film SIDs include a fourth collision suffix, used on both sides as both input and decoder target. Pair SIDs have three semantic codes and no suffix: distinct pairs may collide. Pair token embeddings use a disjoint 3x256 input table. The table is installed for both control and pair to ensure identical named-parameter initialization within each seed; it receives gradients only for pair inputs. Saving the pair keys, embeddings, train mask, centroids, codes, diagnostics, per-epoch curves, predictions, best/last checkpoints and SHA provenance permits analysis and reuse. Pair histories use a padded 56-token array because a 19-item input can contain 56 tokens (a full 20-item history contains 55); control uses 80. Padding is masked.

Four mini-TIGER trainings: control/pair, seeds 42/101 for both quantizer and generator, 30 epochs, validation every 5, FP16, SDPA, Adam 1e-3, effective and physical batch 512. Paired models use exactly the same individual-movie index and same generator initial weights within each seed. Seed comparisons confound generator and quantizer seeds: this is a screen, not a variance decomposition. Always compare fixed epochs and validation-selected metrics, and do not claim convergence or causal compression without further controls. Sentence-T5 preprocessing and the frozen pair quantizer are an additional cost; evaluate training/serving latency end to end before claiming an efficiency win. No test access.
