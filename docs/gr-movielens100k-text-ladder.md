# MovieLens-100K: быстрый эксперимент с накоплением текстовых полей

Пользователь остановил ML-1M и выбрал ML-100K для проверки токенизации.
Конфиг: `experiments/movielens100k_text_ladder_2t4.json`.
Старый `carasik/rhpr-ml1m-text-ladder` подтверждён как CANCEL_ACKNOWLEDGED;
его нельзя возобновлять или перезапускать вместо нового эксперимента.

## Данные и сопоставление фильмов

Официальный архив: https://files.grouplens.org/datasets/movielens/ml-100k.zip .
SHA256: `50d2a982c66986937beb9ffb3aa76efe955bf3d5c6b761f4e3a7cd717c6a3229`.
Исходно 100 000 оценок, 943 пользователя, 1 682 item ID.

**Movie ID не переносимы между ML-100K и ML-1M.** GoldenEye, например, имеет
ID2 и ID10 соответственно. Использован явный мост к прежнему проверенному
каталогу метаданных: прямой IMDb ID из старого URL, когда он есть, иначе
единственное точное совпадение названия/алиаса и года в GroupLens/TMDB.
Нормировка ограничена HTML, регистром, диакритикой, пунктуацией, конечными
артиклями и явно указанными алиасами. Fuzzy match отсутствует. Это не новая
независимая ручная проверка содержимого всех постеров/сюжетов.

- 1 667 исходных ID сопоставлены, 13 не сопоставлены, два неоднозначны.
- После требования полного TMDB rich4 и готового Zenodo ViT остаются
  1 288 исходных ID с 91 767 оценками.
- 15 из этих ID — дубли уже сопоставленных фильмов. Они объединены по общему
  внешнему фильму в минимальный ML-100K ID; каноническое название сохраняется
  из официального `u.item`, включая год. Неоднозначные фильмы не объединяются.
- Для повторных оценок одним пользователем одного канонического фильма
  оставлена последняя по времени; при равном времени — стабильный source-ID
  tie-break, без предпочтения высокого рейтинга. Удалено 298 таких повторов.
- Итог: **1 273 фильма, 943 пользователя, 91 469 оценок** до временного split.

Скрипт `scripts/prepare_movielens100k_text_ladder.py` сохраняет полный bridge,
исключённые/неоднозначные ID, соответствия канонических ID и хеши источников.
Название, год и жанры взяты из ML-100K; длительность, keywords, все актёры и
режиссёры — из сопоставленных замороженных TMDB-полей. Постеры не подаются в
этот текстовый эксперимент: их покрытие задаёт общую будущую мультимодальную
подвыборку. Эмбеддинги/кодбуки/веса остановленного ML-1M не переиспользуются.

## Неизменённый протокол

Семь накопительных вариантов: исходное название с годом → +жанры → +явное
поле Year → +длительность → +TMDB keywords → +актёры → +режиссёры.
Ступень Year повторяет информацию, уже присутствующую в названии.
Overview, user tags, reviews и popularity не включаются.

Один frozen Sentence-T5-base, лимит2 048; максимальный текст1 587токенов,
обрезки нет. Native GRID RQ-VAE3×256/latent64/3 000шагов/FP32. Буфер
инициализации1 273 равен полному меньшему каталогу; остальные настройки
квантователя сохранены. Генератор — прежний TIGER4+4/d128/FF1024,
4 977 920параметров; совпадение инициализации с прошлым контролем проверено:
`5f4a24fa8c9b5f7063739fd44822fd0a5f98eff91c7e882563d32529b0c5abff`.

По20полных эпох, FP16, Adam1e-3, batch256/physical128, latest20history,
seed42. Validation на5/10/15/20, выбор по itemNDCG@10, один test выбранного
чекпоинта. Full catalogue, free beam20, без sampled negatives и seen-mask,
как в предыдущем контроле. Две T4, отдельные workers по4/3варианта.

У каждого пользователя по одному target из двух последних РАЗНЫХ timestamp-
групп. Остальные события этих двух групп исключены из обучения (2 042события).
При обучении доступны только строго более ранние timestamp; одновременные
цели получают один и тот же предшествующий контекст. Все943пользователя
допустимы, исключений из-за недостатка временных групп нет. Все оценки1–5
сохранены; это предсказание следующей оценки, не точного порядка просмотра.

Итоговые бюджеты: **87 541 TRAIN-событие, 85 470 обучающих целей/эпоху,
943 validation и943test-примера**. На вариант приходится1 709 400целей за20эпох.
По отношению к ML-1M целей в10,44раза меньше. При ранее наблюдавшихся600секундах
за892 574примера грубый ориентир — около57секунд на эпоху. Вся сессия на2×T4
оценена в1,5–2часа с подготовкой; это оценка, не новый GPU-замер.
