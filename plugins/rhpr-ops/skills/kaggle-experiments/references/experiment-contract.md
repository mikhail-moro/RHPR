# Experiment contract

- Config path: `experiments/<name>.json`
- Stable entry point: `kaggle/run.py`
- Private kernel metadata: generated by `scripts/build_kaggle_bundle.py`
- Required outputs: `metrics.json`, `summary.md`, `run-manifest.json`
- Metrics: flat, finite JSON scalars only
- Reproducibility: include seed, configuration, Git SHA, start/end time

The `kaggle` object may contain `dataset_sources`, `competition_sources`,
`kernel_sources`, and `model_sources`; each value is a list of Kaggle source
identifiers. Keep `enable_internet` false unless a concrete experiment requires
it and the user approves the change.

The unattended workflow authenticates with `KAGGLE_API_TOKEN`. Interactive MCP
authentication is OAuth and is intentionally separate.
